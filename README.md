# kite-callback

Public static page for a Kite Connect login redirect. It reads `request_token` and `status` from the query string and shows the token so it can be pasted into a local session tool.

No server-side processing, no analytics, no external scripts, and no network requests from the page itself.

Set the Kite app Redirect URL to exactly:

https://yellowgram.github.io/kite-callback/index.html
